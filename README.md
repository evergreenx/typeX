# typeX

A modern, minimal typing tutor — structured lessons, a live finger-color keyboard guide, real-time WPM/accuracy, and an error heatmap that shows you exactly which keys trip you up.

Inspired by the classic Mavis Beacon curriculum, rebuilt with a Monkeytype-style distraction-free interface.

## Features

- **Structured lessons** progressing row by row (home row → top row → bottom row → numbers → punctuation), unlocked in sequence
- **Live finger-color keyboard** highlighting the next key and which finger should hit it
- **Real-time WPM & accuracy** while you type
- **Results screen with an error heatmap** — see which keys you fumble most
- **Free Practice mode** with rotating quotes
- **Local progress tracking** — streaks, best WPM, completed lessons (no account needed)

## Stack

Next.js (App Router) · TypeScript · Tailwind CSS

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
